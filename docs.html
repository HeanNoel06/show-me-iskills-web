Descripción general

Show Me iSkills es una aplicación de escritorio que acompaña actividades físicas, deportivas, de movilidad y rehabilitación. Su interfaz web se sirve localmente y se presenta en una ventana nativa. Rango, el asistente, guía las sesiones con voz, texto y subtítulos.

La versión documentada es 3.2.0.0.

Arquitectura

La aplicación combina un backend en Python con una interfaz web local:

  • Shell nativo: ventana con PyQt6 WebEngine y puente pywebview entre la interfaz y Python.
  • Servidor local: HTTP y WebSocket para la comunicación en tiempo real.
  • Runtime de visión: captura, detección, fusión y eventos en un módulo propio (vision_runtime).
  • Motor de Skills: carga paquetes declarativos y ejecuta sesiones con estado persistente.
  • Persistencia: base de datos local SQLite.

Visión por computadora

La cámara se procesa con OpenCV. La estimación de pose usa YOLOv8-pose como backend principal y MediaPipe como alternativa; ONNX Runtime ejecuta modelos en CPU o GPU según el equipo. Hay soporte opcional para Kinect V2.

El runtime publica cada observación con su fuente, confianza y estado (confirmed, probable o desconocido). Ninguna capa eleva la certeza de una observación.

Sistema de Skills

Una Skill es un paquete declarativo con manifiesto, ejercicios, enfoques, rutinas, reglas técnicas, métricas, voz y elementos visuales. El motor universal los valida y ejecuta sin correr código del creador.

  • Seis familias: deportiva, preparación física, rehabilitación, psicología deportiva, peso y hábitos, creator.
  • Dieciséis capacidades transversales que se desarrollan con la práctica.
  • Rango Creator crea y publica Skills tras validar ejercicios, reglas, seguridad y métricas.

Seguridad

Las funciones sensibles requieren consentimiento. En rehabilitación, la cadena es: consentimiento, identidad profesional verificada, evaluación funcional revisada, plan versionado y aprobado, y autorización de sesión de un solo uso.

La ayuda urgente detiene la sesión y persiste el incidente antes de esperar cualquier otra respuesta. Las acciones profesionales quedan en una bitácora de auditoría.

Base de datos

Los datos se guardan localmente en SQLite: perfiles, sesiones, métricas observadas, planes clínicos, incidentes y contactos de emergencia por perfil y espacio. Las migraciones agregan columnas sin perder datos existentes.

Frontend

La interfaz está escrita en JavaScript con módulos ES y CSS propio. Incluye la pantalla de inicio centrada en Rango, la biblioteca de Skills, la vista de sesión, paneles de progreso, configuración, accesibilidad (subtítulos de Rango) y la zona de juegos. Los recursos se versionan por hash de contenido.

IA

Rango coordina tres agentes (Coach, Fisioterapeuta y Psicólogo) sobre un estado compartido y comunica una sola decisión. La conversación usa un modelo de lenguaje y la voz se sintetiza con un servicio de texto a voz; las correcciones se priorizan y se deduplican para no saturar al usuario.

Pruebas

El repositorio contiene suites automatizadas en tres niveles: pruebas de Python para el backend y los contratos, pruebas de JavaScript para módulos de la interfaz y pruebas de extremo a extremo con Playwright. Los resultados de cada ejecución se publicarán en QA y pruebas.
