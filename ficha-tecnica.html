Lenguajes y arquitectura 5

Show Me iSkills es una aplicación de escritorio: un núcleo en Python que hace la visión, la IA y los datos, y una interfaz web local que se muestra dentro de una ventana nativa.

Python

Lenguaje

Lenguaje del núcleo: servidor local, visión por computadora, agentes de Rango, base de datos, reportes y conexiones. El código se organiza en módulos «mixin» que se combinan en una sola clase Api.

3.xapp/

JavaScript (módulos ES)

Lenguaje

Toda la interfaz: pantallas, sesiones de entrenamiento, demostraciones 3D, juegos, subtítulos y comunicación con el núcleo. Usa Web Workers para no bloquear la pantalla.

—app/ui/

HTML5 y CSS3

Lenguaje

Estructura y estilos de la interfaz, con temas de color, modo oscuro y animaciones.

—app/ui/index.html, *.css

C++

Lenguaje

Programa auxiliar nativo para el sensor Kinect V2 (opcional). Se compila con CMake y entrega color y profundidad al núcleo de Python.

—app/native/kinect_v2/

YAML

Formato

Políticas declarativas, por ejemplo cuándo escalar una alerta o cómo puntuar el chequeo funcional; se leen con PyYAML.

—app/policies/, app/api/escalation_policy.py

Aplicación de escritorio y servidor local 8

La ventana de la app y el canal entre la interfaz y el núcleo.

PyQt6

Framework

Crea la ventana principal (QMainWindow), la pantalla de inicio y los diálogos nativos para guardar archivos.

≥ 6.5app/main.py, app/hardware_placement.py

PyQt6-WebEngine

Framework

Motor Chromium embebido (QWebEngineView) que muestra la interfaz web dentro de la ventana de escritorio.

≥ 6.5app/main.py

pywebview

Librería

Puente nativo usado para abrir diálogos del sistema, como guardar un reporte PDF.

≥ 5.0app/api/sessions.py

Bottle

Framework

Micro-framework web que define las rutas locales: la interfaz, las llamadas a la Api y las imágenes en vivo de la cámara y del Kinect.

≥ 0.13app/main.py

Waitress

Servidor

Servidor HTTP multihilo que sirve la aplicación Bottle en el propio equipo.

≥ 3.0app/main.py

WebSockets

Protocolo / librería

Canal en tiempo real entre el núcleo y la interfaz: poses, eventos de sesión y estados de Rango sin esperar a que la interfaz pregunte.

≥ 13.0app/main.py (_start_ws_server)

python-dotenv

Librería

Carga las claves y la configuración desde un archivo .env local, sin escribirlas en el código.

≥ 1.0app/main.py

multiprocessing

Librería estándar

Ejecuta los modelos pesados u opcionales en un proceso aparte, para que un fallo del modelo no cierre la app.

—app/vision_runtime/isolated_worker.py

Visión por computadora 17

Todo lo que convierte la imagen de la cámara en puntos del cuerpo, ángulos y fases del movimiento. Se ejecuta en el equipo del usuario.

OpenCV

Librería

Captura y procesa el video: lectura de cámara, conversión de color, dibujo de superposiciones, análisis de videos en Rango Video Lab, estimación de la orientación de la cabeza (solvePnP) y respaldo de inferencia con cv2.dnn.

≥ 4.8app/api/cv_mixin.py, app/video_lab/

MediaPipe (Python)

Framework

Hand Landmarker (21 puntos por mano), Face Landmarker (malla del rostro) y pose como respaldo. Se mantiene en la rama 0.10 porque la versión 1.0.1 falló al cargar el modelo de rostro.

0.10.xapp/api/cv_mixin.py, app/api/face_mixin.py

MediaPipe Tasks Vision (web)

Framework

Versión para navegador: Hand, Face y Pose Landmarker corriendo en un Web Worker de la interfaz.

0.10.14app/ui/inference-worker.js

YOLOv8-pose (Ultralytics)

Modelo de IA

Motor de pose en vivo por defecto. Usa la GPU con CUDA automáticamente si existe; en una GPU de 4 GB se midieron más de 40 FPS.

yolov8s-poseapp/vision_runtime/adapters.py

RTMPose-X WholeBody (rtmlib)

Modelo de IA

133 puntos (cuerpo, rostro y manos). Más detallado que YOLOv8-pose; se ofrece como motor opcional y corre en CPU.

rtmlib ≥ 0.0.13app/api/rtmpose_mixin.py

YOLO11n-seg (Ultralytics)

Modelo de IA

Segmentación: obtiene la silueta de la persona y sus regiones del cuerpo.

yolo11n-seg.ptapp/api/segmentation_mixin.py

YOLO11 (detección)

Modelo de IA

Detección de objetos en escena, por ejemplo un balón, cuando la Skill lo necesita.

yolo11app/ml/ball_tracker.py, app/api/sports_tracker_mixin.py

Ultralytics

Framework

Framework que carga y ejecuta los modelos YOLO (pose, segmentación y detección).

≥ 8.3app/vision_runtime/adapters.py

ByteTrack (supervision)

Algoritmo

Seguimiento de varias personas u objetos: les asigna un ID estable entre cuadros.

supervision ≥ 0.22app/api/sports_tracker_mixin.py

Depth Anything V2 (small)

Modelo de IA

Estima la profundidad de la escena con una sola cámara normal, de forma local y muestreada.

depth-anything-v2-smallapp/vision_runtime/adapters.py, models/

HSEmotion (enet_b0)

Modelo de IA

Reconoce la emoción del rostro (~14 MB, viable en CPU) para que el agente Psicólogo adapte el tono.

hsemotion-onnx ≥ 0.1app/api/emotion_mixin.py

ArcFace

Modelo de IA

Genera la «huella» numérica del rostro para reconocer el perfil activo.

ONNXapp/api/face_embedder.py, app/ml/face_arcface.py

L2CS-Net (opcional)

Modelo de IA

Seguimiento de la mirada por el iris (±3–5°). Si no está instalado, se usa la orientación de la cabeza (±15°) sin dependencias extra.

opcionalapp/api/gaze_mixin.py

Clasificador de fase propio

Modelo de IA

Red neuronal propia: recibe 8 ángulos articulares y sus 8 velocidades y decide la fase (neutral, bajando, subiendo). Se entrena con scikit-learn y se exporta a ONNX.

phase_classifier_v1.onnxapp/ml/generate_model.py, app/ui/onnx-worker.js

Estimador de calidad propio

Modelo de IA

Red neuronal propia que da una calificación de 0 a 1 a la técnica de cada repetición.

quality_estimator_v1.onnxapp/ml/generate_model.py

NumPy

Librería

Cálculo numérico: ángulos, velocidades, suavizado y matrices de los modelos.

≥ 1.26app/video_lab/, app/ml/

simplejpeg

Librería

Codificador JPEG basado en libjpeg-turbo, de 3 a 5 veces más rápido, para mandar la imagen en vivo a la interfaz.

≥ 1.7app/api/cv_mixin.py

Motores de inferencia 5

Los programas que ejecutan los modelos de IA en el equipo.

ONNX Runtime

Motor

Ejecuta los modelos ONNX. Usa DirectML en Windows (GPU sin instalar CUDA) y CPU en Linux y macOS; si no está disponible, recurre a cv2.dnn.

≥ 1.20app/vision_runtime/adapters.py, app/api/face_embedder.py

ONNX Runtime Web

Motor

Ejecuta en la interfaz, con WebAssembly, el clasificador de fase y el estimador de calidad.

≥ 1.21app/ui/onnx-worker.js, app/ui/vendor/ort.min.js

PyTorch / CUDA

Framework

Acelera YOLO en tarjetas NVIDIA cuando existen; no se requiere configuración adicional.

vía Ultralyticsapp/vision_runtime/adapters.py

scikit-learn

Librería

Entrena los modelos propios (perceptrón multicapa) a partir de datos de sesiones.

≥ 1.3app/ml/generate_model.py

skl2onnx y ONNX

Librería

Convierten los modelos entrenados al formato ONNX para ejecutarlos en la app y en la interfaz.

≥ 1.16 / ≥ 1.15app/ml/generate_model.py

Inteligencia artificial y lenguaje 3

El razonamiento de Rango y sus tres agentes: Coach, Fisioterapeuta y Psicólogo.

OpenAI GPT-4o mini

API · Modelo de lenguaje

Razonamiento de los agentes y conversación con Rango. El modelo se puede cambiar con la variable OPENAI_MODEL.

configurable (OPENAI_MODEL)app/api/agents_mixin.py, app/api/chat.py, app/api/reasoning_mixin.py

Modelo de visión de OpenAI

API · Modelo multimodal

Analiza cuadros de la cámara cuando Rango necesita describir la escena; solo se usa en funciones que lo piden.

configurable (OPENAI_VISION_MODEL)app/api/vision_mixin.py, app/api/openai_client.py

Librería oficial de OpenAI

Librería

Cliente para llamar a los modelos de lenguaje, visión y voz de OpenAI.

≥ 1.0app/api/openai_client.py

Voz: escuchar y hablar 7

Cómo Rango te escucha y te contesta, con respaldos para que nunca se quede callado.

Whisper

API · Modelo de voz

Convierte tu voz en texto. Usa OpenAI (whisper-1) o Groq (whisper-large-v3).

whisper-1 / whisper-large-v3app/api/voice.py, app/api/chat.py

Google Speech Recognition

API

Respaldo automático cuando Whisper no está disponible.

vía SpeechRecognitionapp/api/voice.py

SpeechRecognition

Librería

Gestiona el micrófono y la palabra de activación «Rango».

≥ 3.10app/api/voice.py, app/api/sr_worker.py

PyAudio

Librería

Acceso de bajo nivel al micrófono (usa PortAudio del sistema).

≥ 0.2.14app/api/sr_worker.py

ElevenLabs (Flash v2.5)

API · Modelo de voz

La voz principal de Rango (texto a voz). Si falla, espera 5 minutos antes de reintentar.

eleven_flash_v2_5app/api/system.py

Edge TTS

Librería

Voces neuronales gratuitas como respaldo cuando no hay clave de ElevenLabs.

≥ 7.0app/api/system.py

Web Speech API

API del navegador

Último respaldo de voz dentro de la interfaz (speechSynthesis).

—app/ui/training/rango-narration.js

Datos, seguridad y reportes 6

Dónde se guarda tu información y cómo se protege.

SQLite

Base de datos

Base de datos principal, local: perfiles, sesiones, intentos de Skill, progreso y contactos de emergencia.

sqlite3app/api/db.py

cryptography (AES-256-GCM)

Librería

Plataforma / API

fpdf2

Librería

Conexiones, emergencias y sensores 5

Servicios y dispositivos externos. Todos son opcionales salvo la cámara.

Twilio

API

Llamada telefónica real a los contactos de emergencia (Calls.json), con seguimiento del estado de la llamada.

REST 2010-04-01app/api/emergency_call_provider.py

Telegram Bot API

API

Dos bots: «Alertas» para avisos urgentes y «Reportes» para resúmenes; además recibe comandos.

Protocolo / librería

Sensor / librería

Glosario

Qué significa cada tipo de tecnología.

Lenguaje

El idioma en que se escribe el programa.

Framework

Una estructura base que organiza la aplicación; el equipo llena las partes.

Librería

Código listo que la aplicación llama para una tarea concreta.

Modelo de IA

Un sistema entrenado con datos que reconoce patrones, como el cuerpo o la voz.

Motor

El programa que ejecuta los modelos de IA.

API

Un servicio externo con el que la aplicación se comunica, normalmente por internet.

Algoritmo

Una receta de pasos para resolver un problema.

Protocolo

Las reglas para que dos sistemas se comuniquen.

Base de datos

Donde se guarda la información de forma ordenada.

Herramienta

Programa que ayuda a desarrollar, revisar o probar el código.

No hay tecnologías que coincidan con esa búsqueda.

Inventario tomado del código del proyecto (requirements, package.json y módulos de la app). Las APIs externas — OpenAI, ElevenLabs, Groq, Google, Twilio, Telegram y Supabase — solo se usan cuando la función está configurada; la visión por computadora se procesa en el equipo del usuario.
